# Code of conduct

Be respectful and keep discussion about the work. Harassment, personal attacks
and discriminatory language are not welcome in issues, pull requests or any
other project space.

This project follows the spirit of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Maintainers may edit or remove contributions that break these rules and may
block repeat offenders. To report a conduct problem, use the private
**Report a vulnerability** form on the Security tab and say it is a conduct
report.
